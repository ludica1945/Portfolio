Proyecto personal / Noviembre 2026

MICHOWARE_
De una PC a una empresa.

Un simulador offline para Windows sobre Papatolio, un desarrollador que convierte una computadora rescatada en una empresa tecnológica. La experiencia combina una campaña narrativa con sistemas de desarrollo, gestión y crecimiento.

Python 3.11+PygameSQLiteWindows
01 / Sistemas del juego

Una simulación que
crece con cada decisión.

Campaña

Siete capítulos

Una historia de progreso con objetivos y continuidad en modo infinito después del final.

Desarrollo

Crear y publicar

Investigación, componentes, desarrollo, pruebas y publicación de software con distintas formas de generar ingresos.

Gestión

Un negocio en marcha

Usuarios, reputación, gastos, campañas, contratación y mejoras conectan las decisiones técnicas con el crecimiento de la empresa.

Guardado local

Partidas privadas

Las partidas se guardan en SQLite en el propio dispositivo. El juego no requiere Internet ni recopila información personal.

02 / Tecnología y enfoque

Una experiencia
local y accesible.

Hecho para Windows · interfaz y arte generados localmente

El proyecto está escrito en Python y usa Pygame para la interfaz y la simulación, y SQLite para los guardados. La música chiptune y el arte de estilo pixel se generan dentro del juego. Los incidentes y amenazas son ficticios y educativos: el programa no descarga ni ejecuta malware, no abre enlaces y no realiza conexiones de red.
